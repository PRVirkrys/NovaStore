# Nova Shop Practice

Proyecto de práctica en Angular para reforzar conceptos fundamentales del framework a través de una interfaz tipo e-commerce.

## Objetivo

El objetivo principal de este proyecto es practicar la estructura y comunicación entre componentes en Angular, separando responsabilidades y preparando una base clara para trabajar con servicios, modelos y eventos.

## Conceptos practicados

- Componentes standalone
- Modelos e interfaces
- Servicios
- Comunicación padre a hijo con `@Input`
- Comunicación hijo a padre con `@Output`
- Emisión y escucha de eventos
- Renderizado de listas
- Manejo básico de estado
- Carrito de compras
- Favoritos
- Estructura visual con HTML y SCSS

## Estado del proyecto

Proyecto en desarrollo con datos hardcodeados para practicar progresivamente la lógica de Angular.
